# Namio – Prüf-Checkliste (v0.20)

Zum Abhaken auf Tablet **und** Handy. Bei jedem Punkt: funktioniert es, sieht es gut aus, ist es verständlich?

## Erster Start
- [ ] App-Sperre erscheint (Fingerabdruck/Gesicht/Muster); Abbrechen lässt die App gesperrt
- [ ] Hinweis „Bevor du echte Daten eingibst“ erscheint einmal, danach nie wieder
- [ ] Demoklasse 7b mit 24 Kindern und Sitzplan „Klassenraum“ ist da
- [ ] Erinnerung „Schuljahr vorbei?“ (nur 15.6.–31.8.) lässt sich wegklicken und bleibt weg

## Klassen & Schüler
- [ ] Klasse anlegen, ⋮ → löschen (mit Rückfrage); Fortschritt in Prozent steigt nach Quizrunden
- [ ] Schüler anlegen (Vorname/Nachname/Geschlecht), Felder ändern → „Speichern“ erscheint oben
- [ ] Foto aufnehmen: Vorschau quadratisch, Gesichtsrahmen, Frontkamera-Wechsel, Foto landet im Raster
- [ ] Foto aus Galerie (nur Bildauswahl, kein Vollzugriff), Avatar wählen, Foto entfernen
- [ ] CSV-Import: Datei aus Untis/Excel wählen, Spalten prüfen, Vorschau, importieren
- [ ] Löschen eines Schülers/einer Klasse entfernt auch die Fotodateien (Galerie zeigt nie Schülerfotos)

## Quiz (jeder Modus einmal komplett)
- [ ] Foto → Name (Auswahl): 4 Namen, Ablenker sind gleichgeschlechtlich, Feedback grün/rot, Auto-Weiter
- [ ] Foto → Name (Tippen): Tippfehler ok (Lina statt Lena), falscher Name zeigt richtigen
- [ ] Name → Foto: 9 Gesichter, Treffer markiert
- [ ] Sitzplan: „Wo sitzt …?“, Platz antippen; ohne Sitzplan kommt der Hinweis
- [ ] Speedrun: 60 s, Zähler, Ergebnis ohne Lernstand-Änderung
- [ ] Ergebnis: Quote, Fehlerliste mit „verwechselt mit“, „Fehler wiederholen“
- [ ] Quizauswahl: Fälligkeitszahlen sinken nach der Runde; nach 10 min sind Box-2-Karten wieder fällig
- [ ] Statistik: Boxverteilung, Trefferquote-Balken, Verwechslungspaare

## Sitzplan
- [ ] Neuer Plan mit Vorlage (Doppeltische / U-Form / Gruppen / je Kind ein Tisch), mit/ohne Vorbelegung
- [ ] Gesperrt beim Öffnen; Schloss entsperrt; Würfel lost aus (Platz blinkt); Mischen (gesperrt mit Rückfrage)
- [ ] Bearbeiten: Kind ziehen, zwei Kinder antippen = tauschen, Tisch ziehen, Tisch antippen → Werkzeuge
- [ ] Werkzeuge: ±15°, ±45°, Plätze +/−, Breite +/−, Duplizieren, Beschriften (Pult/PC), Löschen, Rückgängig
- [ ] Mehrfachauswahl (langer Druck): gemeinsam ziehen, drehen, Zeile/Spalte/Drehung/Abstand ausrichten
- [ ] Zwei-Finger-Drehung auf markierten Tischen
- [ ] Blickrichtung (vom Pult / wie auf Papier), Zoom (Pinch, Buttons), Plan kopieren, als Standard
- [ ] Als PDF speichern (mit/ohne Fotos) → Datei öffnen, ausdrucken
- [ ] Handy: Plan lesbar, seitlich scrollbar; Querformat

## Einstellungen & Daten
- [ ] App-Sperre aus/an; Blickrichtung; neue Karten pro Runde wirkt in der nächsten Runde
- [ ] Export mit Passwort → Datei; Alle Daten löschen → leer; Import mit falschem Passwort scheitert, mit richtigem alles zurück
- [ ] Übertragung Tablet → Handy per Datei (z. B. über den Dateimanager/NAS)

## Rahmen
- [ ] Deutsch/Englisch (Systemsprache umschalten)
- [ ] Große Schrift (Einstellungen → Anzeige → Schriftgröße 130 %): nichts abgeschnitten
- [ ] TalkBack: Karten und Fotos werden sinnvoll vorgelesen
- [ ] Drehen Hoch/Quer in allen Screens
- [ ] Keine Netzwerkzugriffe (App hat keine INTERNET-Berechtigung – z. B. in den App-Infos prüfen)
